# 分支结构

### 条件判断与缩进

Python 使用 `if` 判断条件，条件后面要加冒号，属于这个分支的代码需要缩进，通常使用四个空格。与 C++ 不同，Python 用缩进划分代码块，不使用花括号。

下面沿用原练习中的身高、体重输入来演示分支。代码里的区间用于练习条件判断。

### 单分支结构

当条件为真时执行 `if` 中的代码；条件为假时跳过它。

```python
height = float(input('身高(cm)：'))
weight = float(input('体重(kg)：'))
bmi = weight / (height / 100) ** 2
print(f'{bmi = :.1f}')

if 18.5 <= bmi < 24:
    print('BMI 在 [18.5, 24) 区间内')
```

**输入与格式化输出**

`input` 返回字符串，`float` 将输入转换为浮点数。运行示例时输入正数，身高不能为零。`f'{bmi = :.1f}'` 会输出变量名和保留一位小数后的值。

**连续比较**

`18.5 <= bmi < 24` 等价于 `18.5 <= bmi and bmi < 24`，表示两个条件同时成立。

### 双分支结构

`if ... else ...` 在两条路径中选择一条执行。`else` 后面不写条件，但同样需要冒号。

```python
height = float(input('身高(cm)：'))
weight = float(input('体重(kg)：'))
bmi = weight / (height / 100) ** 2
print(f'{bmi = :.1f}')

if 18.5 <= bmi < 24:
    print('BMI 在 [18.5, 24) 区间内')
else:
    print('BMI 不在 [18.5, 24) 区间内')
```

### 多分支结构

使用 `if ... elif ... else ...` 判断多个条件。程序从上到下检查，执行第一个条件为真的分支后，跳过后面的分支。

```python
height = float(input('身高(cm)：'))
weight = float(input('体重(kg)：'))
bmi = weight / (height / 100) ** 2
print(f'{bmi = :.1f}')

if bmi < 18.5:
    print('BMI 小于 18.5')
elif bmi < 24:
    print('BMI 在 [18.5, 24) 区间内')
elif bmi < 27:
    print('BMI 在 [24, 27) 区间内')
elif bmi < 30:
    print('BMI 在 [27, 30) 区间内')
elif bmi < 35:
    print('BMI 在 [30, 35) 区间内')
else:
    print('BMI 大于或等于 35')
```

例如，进入 `elif bmi < 24` 时，前面的 `bmi < 18.5` 已经不成立，所以不必再次写下限判断。多个独立的 `if` 会分别检查条件，与这里的多分支结构不同。
