# 常用数据结构之字典

[对应练习代码](<10.字典.py>)

字典 `dict` 用键值对保存关联数据。键必须可哈希且不能重复；给已有键赋值会更新它的值，给新键赋值会添加键值对。Python 3.7 起字典保证保持插入顺序。

### 定义、成员判断与索引

`key in person` 判断的是键，不是值。`person[key]` 读取不存在的键会抛出 `KeyError`；`person.get(key, 默认值)` 可以提供默认值。下面保留原练习数据作为示例。

```python
person = {'name': '王大锤', 'age': 55, 'height': 168, 'weight': 60, 'addr': '成都市武侯区科华北路62号1栋101'}
# 成员运算
print('name' in person)
print('tal' in person)

# 索引
print(person['name'])
print(person['addr'])
person['age']=25
person['height']=178
person['signature']='你的男朋友是一个盖世垃圾，他会踏着五彩祥云去迎娶你的闺蜜'
print(person)

# 循环遍历
for key in person:
    print(f'{key}:\t{person[key]}')
```

### 遍历键、值和键值对

直接遍历字典得到键。`keys()`、`values()`、`items()` 分别返回键、值和键值对的视图；`for key, value in person.items()` 同时取出键和值。

```python
person = {'name': '王大锤', 'age': 25, 'height': 178, 'addr': '成都'}
print(person.keys())
print(person.values())
print(person.items())

for key,value in person.items():
    print(f'{key}:\t{value}')
```

### 删除键值对

`pop(key)` 删除指定键并返回值；不提供默认值且键不存在时会报错。`popitem()` 删除并返回最后插入的键值对，空字典调用会报错。

```python
person = {'name': '王大锤', 'age': 25, 'height': 178, 'addr': '成都市武侯区科华北路62号1栋101'}
print(person.pop('age'))
print(person.popitem())
for key,value in person.items():
    print(f'{key}:{value}')
```

### 应用：统计字母频次

遍历输入字符串，只统计英文字母。`cnt.get(ch, 0) + 1` 实现计数；`sorted(cnt, key=cnt.get, reverse=True)` 按计数从大到小返回键列表。这里区分大小写，统计的是字母而不是单词。

例如输入 `abAab!`，计数为 `a: 2`、`b: 2`、`A: 1`；频次相同时保留原有键的相对顺序。

```python
sentence = input('please enter a sentence:')
cnt={}
for ch in sentence:
    if 'A' <= ch <= 'Z' or 'a' <= ch <= 'z':
        cnt[ch]=cnt.get(ch,0)+1

sorted_cnt=sorted(cnt,key=cnt.get,reverse=True)
for key in sorted_cnt:
    print(f'{key} 出现了 {cnt[key]} 次.')
```
