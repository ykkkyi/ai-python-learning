## 阅读与运行

在 VS Code 中打开 `.md`，按 `Ctrl+Shift+V` 预览。代码块按正文顺序阅读，有些示例依赖前面定义的变量。需要终端输入的示例，正文会说明输入内容。

原始 `.py` 保留学习过程；笔记中的修正示例与原代码可能不同。例如运算符练习中的变量应先定义，列表和元组练习的输出注释应与当前数据一致。字符串笔记还包含故意展示异常的示例，不能把整篇代码直接拼接运行。
