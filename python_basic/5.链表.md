# 常用数据结构之列表

[对应练习代码](<5.链表.py>)

文件名沿用原练习；这里学习的是 Python 的列表 `list`，不是链表。列表有序、可修改，能够保存重复元素和不同类型的对象。

### 列表的定义

使用方括号 `[]` 定义列表，用逗号分隔元素。

```python
items1 = [35, 12, 99, 68, 55, 35, 87]
items2 = ['Python', 'Java', 'Go', 'Kotlin']
items3 = [100, 12.3, 'Python', True]
print(items1)  # [35, 12, 99, 68, 55, 35, 87]
print(items2)  # ['Python', 'Java', 'Go', 'Kotlin']
print(items3)  # [100, 12.3, 'Python', True]
```

### 拼接、重复与成员运算

`+` 拼接列表，`*` 重复元素；`in` 和 `not in` 判断元素是否存在，结果为布尔值。

```python
items5 = [35, 12, 99, 45, 66]
items6 = [45, 58, 29]
items7 = ['Python', 'Java', 'JavaScript']
print(items5 + items6)  # [35, 12, 99, 45, 66, 45, 58, 29]
print(items6 + items7)  # [45, 58, 29, 'Python', 'Java', 'JavaScript']
items5 += items6
print(items5)  # [35, 12, 99, 45, 66, 45, 58, 29]

print(items6 * 3)  # [45, 58, 29, 45, 58, 29, 45, 58, 29]
print(items7 * 2)  # ['Python', 'Java', 'JavaScript', 'Python', 'Java', 'JavaScript']

print(29 in items6)  # True
print(99 in items6)  # False
print('C++' not in items7)     # True
print('Python' not in items7)  # False
```

### 索引与修改

正向索引从 `0` 开始，`-1` 表示最后一个元素。下面将索引 `-4` 的元素改为整数 `11`，后面的切片以修改后的列表为准。

```python
items8 = ['apple', 'waxberry', 'pitaya', 'peach', 'watermelon']
print(items8[0])
print(items8[2])
print(items8[4])
print(items8[-1])
print(items8[-5])
items8[-4]=11
print(items8)
```

### 切片运算

`items[start:stop:step]` 不包含终点。步长为正时通常从左向右取值；步长为负时反向取值。`[::-1]` 可获得反向排列的新列表。下面修正了原代码中未随列表修改而更新的输出注释。

```python
print(items8[1:3:1])     # [11, 'pitaya']
print(items8[0:3:1])     # ['apple', 11, 'pitaya']
print(items8[0:5:2])     # ['apple', 'pitaya', 'watermelon']
print(items8[-4:-2:1])   # [11, 'pitaya']
print(items8[-2:-6:-1])  # ['peach', 'pitaya', 11, 'apple']


print(items8[1:3])     # [11, 'pitaya']
print(items8[:3:1])    # ['apple', 11, 'pitaya']
print(items8[::2])     # ['apple', 'pitaya', 'watermelon']
print(items8[-4:-2])   # [11, 'pitaya']
print(items8[-2::-1])  # ['peach', 'pitaya', 11, 'apple']
```

### 遍历列表

需要索引时使用 `range(len(...))`；只需要元素时直接遍历列表。

```python
languages = ['python','java','c++','kotlin']
for index in range(len(languages)):
    print(languages[index])

for x in languages:
    print(x)
```

### 应用：统计随机点数

用长度为 6 的列表保存计数，点数 `face` 对应索引 `face - 1`。`randrange(1, 7)` 的结果为 1～6，六个计数之和应为 6000；具体分布每次可能不同。

原练习署名：骆昊，Version 1.1。

```python
import random

counters = [0] * 6
# 模拟掷色子记录每种点数出现的次数
for _ in range(6000):
    face = random.randrange(1, 7)
    counters[face - 1] += 1
# 输出每种点数出现的次数
for face in range(1, 7):
    print(f'{face}点出现了{counters[face - 1]}次')
```
