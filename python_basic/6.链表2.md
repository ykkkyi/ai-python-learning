### 添加和删除元素

`append` 在末尾添加，`insert` 在指定位置插入。`remove` 按值删除，`pop` 按索引删除并返回元素，`clear` 清空列表。

```python
languages = ['python','java','c++']
print(languages)
languages.append('javascript')
print(languages)
languages.insert(1,'SQL')
print(languages)

languages = ['Python', 'SQL', 'Java', 'C++', 'JavaScript']
if 'Java' in languages:
    languages.remove('Java')
if 'Swift' in languages:
    languages.remove('Swift')
print(languages)  # ['Python', 'SQL', 'C++', 'JavaScript']
languages.pop()
temp = languages.pop(1)
print(temp)       # SQL
languages.append(temp)
print(languages)  # ['Python', 'C++', 'SQL']
languages.clear()
print(languages)  # []
```

### remove、del 与 pop

`remove` 只删除第一个匹配元素，不存在时会抛出 `ValueError`。`del items[i]` 按索引删除，但不返回被删元素；需要该元素时使用 `pop(i)`。选择时先看是否需要返回值，不凭某个版本的字节码断言性能。

```python
example=['pp','aa','pp']
example.remove('pp')   #若列表中有多个'pp',list.remove('pp')会删除第一个
print(example)

#del和pop的区别


iteas=['Python','Java','C++']
del iteas[1]
print(iteas)
```

### 元素位置和频次

`index(value, start)` 从指定索引起查找第一个匹配位置；找不到会抛出 `ValueError`。`count` 统计出现次数，不存在时返回 `0`。

```python
items = ['Python', 'Java', 'Java', 'C++', 'Kotlin', 'Python']
print(items.index('Python'))
print(items.index('Python',1))
print(items.count('Python'))
print(items.count('C++'))
print(items.count('yky'))

# 从索引位置3开始查找'Java'
#print(items.index('Java', 3))    # ValueError: 'Java' is not in list
```

### 排序与反转

`sort()` 原地升序排序，`reverse()` 原地反转当前顺序，两者返回值都是 `None`。要保留原列表，可使用 `sorted(items)` 获得新的排序列表。

```python
items=[23,87,32.6,99,6,3,31]
print(items)
items.sort()
print(items)
items.reverse()
print(items)
```

### 列表生成式

基本形式为 `[表达式 for 变量 in 可迭代对象 if 条件]`。下面分别将筛选倍数、元素平方、筛选大于 50 的数写成普通循环和生成式。

```python
#1
items=[]
for i in range(1,100):
    if i%3==0 or i%5==0:
        items.append(i)
print(items)

items1=[i for i in range(1,100) if i%3==0 or i%5==0]
print(items1)

#2
num1=[35, 12, 97, 64, 55]
num2=[]
for x in num1:
    num2.append(x**2)
print(num2)

num3=[x**2 for x in num1 ]
print(num3)


#3
nums1 = [35, 12, 97, 64, 55]
nums2 = []
for num in nums1:
    if num > 50:
        nums2.append(num)
print(nums2)

num3=[x for x in num1 if x>50]
print(num3)
```

### 嵌套列表

二维列表可以用 `scores[行][列]` 访问元素。下面演示固定数据、逐层循环生成数据和嵌套生成式；两段随机示例的分数范围不同，分别是 1～100 和 60～100。

```python
scores = [[95, 83, 92], [80, 75, 82], [92, 97, 90], [80, 78, 69], [65, 66, 89]]
print(scores[0])
print(scores[0][1])


import random

scores=[]
for _ in range(5):
    tmp=[]
    for _ in range(3):
        score=random.randint(1,100)
        tmp.append(score)
    scores.append(tmp)

print(scores)


scores=[[random.randrange(60,101) for _  in range(3)] for _ in range(5)]
print(scores)
```
