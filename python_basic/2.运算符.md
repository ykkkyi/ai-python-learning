# 运算符

### 算术运算符

Python 支持加、减、乘、除、整除、取模和乘方运算。

```python
print(321 + 12)   # 333
print(321 - 12)   # 309
print(321 * 12)   # 3852
print(321 / 12)   # 26.75
print(321 // 12)  # 26
print(321 % 12)   # 9
print(321 ** 12)  # 1196906950228928915420617322241
```

**除法与整除**

`/` 进行普通除法，即使两个操作数都是整数，结果也是浮点数。`//` 表示向下取整的除法，对负数的结果需要特别留意。

```python
print(10 / 2)   # 5.0
print(10 // 3)  # 3
print(-10 // 3) # -4
```

**取模与乘方**

`%` 用来求余数，常用于判断整除关系；`**` 用来计算幂。Python 中的 `^` 是按位异或，不是乘方。

```python
print(10 % 3)       # 1
print(10 % 2 == 0)  # True
print(2 ** 3)      # 8
```

### 赋值与比较

`=` 用于赋值，`==` 用于比较两个值是否相等。读取变量之前，需要先给它赋值。

```python
b = 20
print(b == 20)  # True
print(b == 10)  # False
```

### 海象运算符

Python 3.8 引入了赋值表达式运算符 `:=`，也叫海象运算符。它既把右侧的值赋给变量，又让整个表达式产生这个值，因此可以用在另一个表达式内部。

```python
# 普通赋值不是表达式，下面的写法会产生语法错误。
# print((a = 10))

print((a := 10))  # 10
print(a)          # 10
```

**区分三种写法**

- `a = 10`：把 `10` 赋给变量 `a`。
- `a == 10`：判断 `a` 是否等于 `10`，结果是布尔值。
- `(a := 10)`：把 `10` 赋给 `a`，同时产生值 `10`。
