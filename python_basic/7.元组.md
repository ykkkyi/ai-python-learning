# 常用数据结构之元组

元组 `tuple` 是有序且不可变的序列：创建后不能替换、增加或删除其中的元素引用。若某个元素本身是列表，该列表内部仍可以修改；元组不可变不等于它引用的所有对象都不可变。

### 定义、索引与运算

元组支持长度查询、索引、切片、遍历、成员判断和拼接。比较按元素依次进行；前缀相同时，较短的元组更小。这里修正了原文件拼接结果中与实际变量不一致的注释。

```python
t1 = (35,12,98)
t2 = ('yky',45,True,'kk')

# 查看变量的类型
print(type(t1))
print(type(t2))

# 查看元组中元素的数量
print(len(t1))
print(len(t2))

# 索引运算
print(t1[0])
print(t2[2])
print(t2[-1])


# 切片运算
print(t1[:2])
print(t2[::3])

# 循环遍历元组中的元素
for index in range(len(t1)):
    print(t1[index])
for elem in t2:
    print(elem)

# 成员运算
print(12 in t1)         # True
print(99 in t1)         # False
print('Hao' not in t2)  # True

# 拼接运算
t3 = t1 + t2
print(t3)  # (35, 12, 98, 'yky', 45, True, 'kk')

# 比较运算
print(t1 == t3)            # False
print(t1 >= t3)            # False
print(t1 <= (35, 11, 99))  # False
```

### 空元组与单元素元组

`()` 是空元组。单元素元组必须保留逗号，如 `(100,)`；`(100)` 只是给整数加了括号。

```python
a = ()
print(type(a))  # <class 'tuple'>
b = ('hello')
print(type(b))  # <class 'str'>
c = (100)
print(type(c))  # <class 'int'>
d = ('hello', )
print(type(d))  # <class 'tuple'>
e = (100, )
print(type(e))  # <class 'tuple'>
```

### 打包和解包

逗号分隔的多个值可以打包成元组。解包时变量数要与元素数匹配，否则会产生 `ValueError`。

```python
#打包操作
a=1,10,'yky'
print(type(a))
print(a)

#解包操作
x,y,z=a
print(x,y,z)

#解包时个数不对应
a = 1, 10, 100, 1000
# i, j, k = a             # ValueError: too many values to unpack (expected 3)
# i, j, k, l, m, n = a    # ValueError: not enough values to unpack (expected 6, got 4)
```

### 星号解包

带 `*` 的变量接收剩余元素，得到的是列表，可以为空。同一次解包只能有一个星号目标。原练习在 `i, *j = a` 后还输出旧变量 `k`，这里改成只输出本次解包的 `i`、`j`。

```python
#解包时 通过星号表达式可以把多个元素赋给一个变量，用星号表达式修饰的变量会变成一个列表
a=1,10,100,'yky'
i,j,*k=a
print(i,j,k)
i,*j,k=a
print(i,j,k)
i,*j=a
print(i,j)
i,j,k,*m=a
print(i,j,k,m)
i,j,k,m,*n=a
print(i,j,k,m,n)
n.append('kk')
print(n)
```

### 其他序列的解包

列表、字符串和 `range` 等可迭代对象也支持解包。对字符串解包得到的是字符。

```python
#解包语法对所有的序列都成立，这就意味着我们之前讲的列表、range函数构造的范围序列甚至字符串都可以使用解包语法

a, b, *c =[i for i in range(1,10) if i&1] 
print(a, b, c)
a, b, c = [1, 10, 100]
print(a, b, c)
a, *b, c = 'hello'
print(a, b, c)
```

### 交换变量的值

先计算右侧全部值，再赋给左侧变量，因此可以直接交换变量。第二次赋值基于第一次交换后的结果。

```python
a=11
b=12
c=13
a, b = b, a
a, b, c = b, c, a
```

### 计时与类型转换

`timeit` 用来测量指定代码的运行时间；结果依赖解释器和运行环境。常量元组可能被编译器复用，这个例子不能证明所有元组操作都更快，也不能证明引用的可变对象是线程安全的。`list(infos)` 将元组元素放入新列表。

```python
import timeit
print('%.3f 秒' % timeit.timeit('[1,2,3,4,5,6,7,8,9]',number=1000000))
print('%.3f 秒' % timeit.timeit('(1,2,3,4,5,6,7,8,9)',number=1000000))


infos=('yky',11,True)
print(infos)
print(list(infos))
```
