集合 `set` 保存不重复的可哈希元素，不支持按索引取值。输出顺序不应作为判断正确性的依据；需要稳定展示时可以对可比较的元素使用 `sorted`。空集合要写 `set()`，`{}` 是空字典。

### 集合的定义

使用 `{元素, ...}`、`set(可迭代对象)` 或集合生成式创建集合。重复元素会被去除；字符串传给 `set` 后按字符去重。

```python
set1={1,2,3,3,3,2}
print(set1)

set2={'banana','pitaya','apple','banana','grape'}
print(set2)

set3=set('hellp')
print(set3)

set4=set({1, 2, 2, 3, 3, 3, 2, 1})
print(set4)

set5={num for num in range(1,20) if num %3==0 or num%7==0 }
print(set5)
```

### 成员运算

`in` 判断元素是否属于集合，`not in` 判断元素是否不属于集合。

```python
set1={11,12,13,16}
print(11 in set1)
print(8 in set1)

if 16 in set1:
    print(16)
```

### 交集、并集、差集与对称差

交集 `&` 取共有元素，并集 `|` 取全部不同元素；差集 `A - B` 取仅属于 A 的元素，对称差 `^` 取只属于其中一个集合的元素。方法写法与运算符写法在这里得到相同结果。

```python
set1 = {1, 2, 3, 4, 5, 6, 7}
set2 = {2, 4, 6, 8, 10}

# 交集
print(set1&set2)
print(set1.intersection(set2))

# 并集
print(set1|set2)
print(set1.union(set2))

# 差集
print(set1-set2)
print(set1.difference(set2))

# 对称差
print(set1^set2)
print(set1.symmetric_difference(set2))
```

### 添加、删除与清空

`add` 添加元素；`discard` 删除不存在的元素也不报错；`remove` 删除不存在的元素会抛出 `KeyError`。`clear` 清空集合。

```python
set1={1,10,100}
set1.add(1000)
set1.add(10000)
print(set1)

# 删除元素
set1.discard(10)
if 100 in set1:
    set1.remove(100)
print(set1)

set1.clear()
print(set1)
```

### 不可变集合

`frozenset` 不支持增删元素，但仍支持集合运算。集合的 `<` 表示真子集，而不是按元素大小排序；下面的 `fset1 < fset2` 为 `False`，因为 `7` 不在 `fset2` 中。

```python
fset1=frozenset({1,3,5,7})
fset2=frozenset(range(1,6))

print(fset1)
print(fset2)
print(fset1&fset2)
print(fset1|fset2)
print(fset1-fset2)
print(fset1<fset2)
```
