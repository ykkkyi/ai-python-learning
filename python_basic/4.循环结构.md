# 循环结构

### for-in 循环

`for ... in ...` 用于依次取出可迭代对象中的元素。重复执行固定次数时，可以配合 `range` 使用。

```python
import time

for i in range(2):
    print('hello world')
    time.sleep(1)
```

**不使用循环变量时**

如果只关心重复次数，可以约定用 `_` 作为循环变量。它仍是普通变量，只是用名字表明这里不需要使用它的值。

```python
import time

for _ in range(1):
    print('hello world')
    time.sleep(1)
```

### range 的使用

`range(start, stop, step)` 表示从 `start` 开始、到 `stop` 之前结束，步长为 `step` 的整数序列。起点默认为 `0`，步长默认为 `1`，终点不包含在内。

```python
for i in range(1, 100, 2):
    print(i)  # 依次输出 1、3、5，直到 99
```

**累加求和**

```python
total = 0
for i in range(1, 101):
    total += i
print(f'{total = }')  # total = 5050

total = 0
for i in range(2, 101, 2):
    total += i
print(f'{total = }')  # total = 2550

print(sum(range(1, 101)))  # 5050
```

`+=` 表示累加并赋值；对这里的数值来说，`total += i` 等价于 `total = total + i`。内置函数 `sum` 可以直接对序列求和。

### while 循环

`while` 在每次循环开始前检查条件，只要条件为真就继续执行。循环中需要适时更新变量，让条件最终变为假，或使用 `break` 结束循环。

```python
total = 0
i = 1
while i <= 100:
    total += i
    i += 1
print(f'{total = }')  # total = 5050
```

### break 与 continue

**break：结束当前循环**

```python
total = 0
i = 2
while True:
    if i > 100:
        break
    total += i
    i += 2
print(total)  # 2550
```

**continue：跳过本轮剩余代码**

```python
total = 0
for i in range(1, 101):
    if i & 1:
        continue
    total += i
print(total)  # 2550
```

这里 `i & 1` 是按位与：对这些正整数，奇数的结果为 `1`，偶数的结果为 `0`，所以代码跳过奇数，只累加偶数。也可以写成更直观的 `i % 2 != 0`。

### 嵌套循环

循环内部还可以包含循环。下面外层控制行，内层输出当前行的乘法算式。

```python
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f'{i}*{j}={i * j}', end='\t')
    print()
```

`end='\t'` 将默认的换行改成制表符；内层循环结束后，单独的 `print()` 换到下一行。嵌套循环中的 `break` 只结束它所在的那一层循环。
