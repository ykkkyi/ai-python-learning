# 变量与基本数据类型

### 整数

Python 使用 `int` 表示整数。除了十进制，还可以用 `0b`、`0o`、`0x` 分别表示二进制、八进制、十六进制整数；`print` 默认按十进制输出它们。

```python
print(0b100)  # 4
print(0o100)  # 64
print(100)    # 100
print(0x100)  # 256
```

### 浮点数

Python 使用 `float` 表示浮点数，可以采用小数形式或科学计数法。`e2` 表示乘以 10 的二次方。

```python
print(123.456)    # 123.456
print(1.23456e2)  # 123.456
```

### 字符串

字符串的类型是 `str`，可以用单引号或双引号包围文本。如果字符串内部使用了与外层相同的引号，可以用反斜杠转义。

```python
print('I\'m learning Python')  # I'm learning Python
```

### 使用变量保存数据

**赋值和运算**

使用 `=` 将右侧的值赋给左侧的变量。与 C++ 不同，Python 定义变量时不需要提前声明类型。

```python
a = 45
b = 12
print(a, b)   # 45 12
print(a + b)  # 57
print(a - b)  # 33
print(a * b)  # 540
print(a / b)  # 3.75
```

### 检查变量的类型

内置函数 `type` 可以查看对象的类型。布尔类型为 `bool`，有 `True` 和 `False` 两个值，首字母必须大写。

```python
a = 100
b = 123.45
c = 'hello, world'
d = True
print(type(a))  # <class 'int'>
print(type(b))  # <class 'float'>
print(type(c))  # <class 'str'>
print(type(d))  # <class 'bool'>
```
