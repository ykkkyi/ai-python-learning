## 原始记录与修正示例

`.py` 保留原始练习，`.md` 在发现错误的地方说明原因并给出修正示例。复习时优先阅读这些记录：

- 圆的计算：π 的手写数值有误，参考代码改用 `math.pi`。
- 判断素数：要处理小于 2 的输入，不能把 1 当成素数。
- 水仙花数：十位要用整除 10 后取模，不能用右移一位。
- `77.py`：首轮失败点数中的 11 应为 12，见对应笔记。

随机选号最后一段依赖 `rich`，可在仓库根目录运行 `python -m pip install -r requirements.txt` 安装。
