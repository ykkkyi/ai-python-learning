## 随机验证码

```python
import random
import string

ALL_CHARS = string.ascii_letters + string.digits


def generate_code(*, code_len=4):
    return ''.join(random.choices(ALL_CHARS, k=code_len))


print(generate_code())
print(generate_code(code_len=7))
```

`*` 表示 `code_len` 必须写出参数名传入。每次结果不同，但返回字符串长度应分别为 4 和 7。

## 素数、最大公约数与最小公倍数

素数必须大于 1。判断时只需检查到平方根；最大公约数可用辗转相除法计算。

```python
from math import isqrt


def is_prime(num):
    if num < 2:
        return False
    for divisor in range(2, isqrt(num) + 1):
        if num % divisor == 0:
            return False
    return True


def gcd(x, y):
    x, y = abs(x), abs(y)
    while y != 0:
        x, y = y, x % y
    return x


def lcm(x, y):
    if x == 0 or y == 0:
        return 0
    return abs(x * y) // gcd(x, y)


print(is_prime(17))  # True
print(gcd(12, 18))   # 6
print(lcm(12, 18))   # 36
```

原练习的 `is_prime` 会把 0 和 1 判为素数；`gcd` 的循环条件会让 `gcd(12, 18)` 错误返回 18。上面的版本处理了这些情况。

## 描述性统计

`ptp` 是极差，等于最大值减最小值；方差使用 `n - 1` 作分母，因此这里计算的是样本方差。数据应至少包含两个数，且变异系数要求均值不为 0。

```python
def mean(data):
    return sum(data) / len(data)


def median(data):
    values = sorted(data)
    middle = len(values) // 2
    if len(values) % 2 == 1:
        return values[middle]
    return (values[middle - 1] + values[middle]) / 2


def variance(data):
    if len(data) < 2:
        raise ValueError('样本方差至少需要两个数据')
    average = mean(data)
    return sum((value - average) ** 2 for value in data) / (len(data) - 1)


data = [1, 4, 6, 7, 8, 8, 9]
print(mean(data))      # 6.142857142857143
print(median(data))    # 7
print(max(data) - min(data))  # 8
print(variance(data))  # 7.809523809523809
```

## 双色球随机选号

红球应无放回抽取 6 个，蓝球独立抽取 1 个。原练习把蓝球加入列表后，又在循环中打印了一次，因此会显示两次蓝球；分开返回和显示更清楚。

```python
import random


def choose_balls():
    red_balls = sorted(random.sample(range(1, 34), 6))
    blue_ball = random.randint(1, 16)
    return red_balls, blue_ball


def display_balls(red_balls, blue_ball):
    print('红球:', ' '.join(f'{ball:02d}' for ball in red_balls))
    print(f'蓝球: {blue_ball:02d}')


red_balls, blue_ball = choose_balls()
display_balls(red_balls, blue_ball)
```
