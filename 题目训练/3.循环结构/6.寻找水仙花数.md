# 寻找三位水仙花数

[对应练习代码](<6.寻找水仙花数.py>)

### 思路与知识点

枚举 100～999，拆出个位、十位和百位，检查三位数字的立方和是否等于原数。

### 运行说明与易错点

原练习用 `(i >> 1) % 10` 获取十位，这是右移一位，不是十进制除以 10。下面修正为 `(i // 10) % 10`。

### 整理后的参考代码

下面修正了上述问题；链接中的 `.py` 保留原练习记录，复习时可以对照修改。

```python
for i in range(100,1000):
    a=i%10
    b=(i//10)%10
    c=i//100
    if a**3+b**3+c**3==i:
        print(i)
```

### 检查结果

应依次输出 `153`、`370`、`371`、`407`。
