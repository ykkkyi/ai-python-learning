# 猜数字游戏

[对应练习代码](<3.猜数字游戏.py>)

### 思路与知识点

随机生成 1～100 的整数，根据用户猜测提示偏大或偏小；猜中后结束循环并输出尝试次数。

### 运行说明与易错点

`randrange(1, 101)` 包含 1、不包含 101。`counter` 在读取每次猜测前递增；原练习假定输入为合法整数。

### 练习代码

```python
import random
answer=random.randrange(1,101)
counter=0
while 1:
    counter+=1
    num=int(input('请输入：'))
    if num>answer: 
        print('大了')
    elif num<answer:
        print('小了')
    else:
        print('猜对了')
        break
print(f'你总共猜了{counter}次')
```

### 检查结果

每次根据提示缩小范围，猜中后输出“猜对了”和本次猜测次数。目标值随机，因此没有唯一固定输出。
