# 斐波那契数列

[对应练习代码](<5.Fibonacci sequence.py>)

### 思路与知识点

从 `1, 1` 开始，每一项为前两项之和。用两个变量保存最近两项，通过同时赋值推进。

### 运行说明与易错点

`pref1, pref2 = pref2, pref1 + pref2` 先计算右侧，再赋值；若拆成两次普通赋值，可能错误使用已经更新的变量。

### 练习代码

```python
pref1=1
pref2=1
print(pref1)
print(pref2)
for i in range(3,21):
    pref1,pref2=pref2,pref1+pref2
    print(pref2)
```

### 检查结果

共输出 20 项，开头为 `1, 1, 2, 3, 5`，第 20 项为 `6765`。
