# 100 以内的素数

[对应练习代码](<4.100以内的素数.py>)

### 思路与知识点

枚举 2～100，每个候选数只检查到平方根；遇到因数就停止。

### 运行说明与易错点

原练习从 1 开始枚举，会误输出 1；整理示例把范围改为 `range(2, 101)`。

### 整理后的参考代码

下面修正了上述问题；链接中的 `.py` 保留原练习记录，复习时可以对照修改。

```python
for i in range(2,101):
    is_prime=1
    for j in range(2,int(i**0.5)+1):
        if i%j==0:
            is_prime=0
            break
    if is_prime:
        print(i)
```

### 检查结果

共输出 25 个素数，第一个为 `2`，最后一个为 `97`，不应包含 `1`。
