# 判断素数

[对应练习代码](<1.判断素数.py>)

### 思路与知识点

素数是大于 1 且仅有 1 和自身两个正因数的整数。若有非平凡因数，则至少一个因数不超过平方根。

### 运行说明与易错点

原练习会把 0 和 1 判为素数，负数还可能在计算平方根时报错。下面先判断 `num >= 2`，再使用 `math.isqrt` 获取整数平方根，修正这两个边界问题。

### 整理后的参考代码

下面修正了上述问题；链接中的 `.py` 保留原练习记录，复习时可以对照修改。

```python
from math import isqrt

num = int(input('请输入一个整数：'))
is_prime = num >= 2
if is_prime:
    for i in range(2, isqrt(num) + 1):
        if num % i == 0:
            is_prime = False
            break
if is_prime:
    print(f'{num}是素数')
else:
    print(f'{num}不是素数')
```

### 检查结果

输入 `1`、`0`、`-3`、`9` 应输出不是素数；输入 `2`、`17` 应输出是素数。
