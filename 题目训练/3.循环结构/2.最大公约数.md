# 最大公约数

[对应练习代码](<2.最大公约数.py>)

### 思路与知识点

第一段从大到小枚举公因数；第二段使用辗转相除法，重复把 `(x, y)` 替换为 `(y, x % y)`，直到 `y` 为 0。

### 运行说明与易错点

原脚本包含两次独立演示，所以需要输入两组数据。这里按正整数学习；枚举法尚未处理 0 和负数。

### 练习代码

```python
x=int(input('x='))
y=int(input('y='))
for i in range(x,0,-1):
    if x%i==0 and y%i==0:
        print(f'最大公约数是{i}')
        break

x=int(input('x='))
y=int(input('y='))
while y!=0:
    tmp=x%y
    x=y
    y=tmp
print(f'最大公约数是{x}')
```

### 检查结果

依次输入 `48`、`18`、`48`、`18`，两种方法都输出最大公约数为 `6`。
