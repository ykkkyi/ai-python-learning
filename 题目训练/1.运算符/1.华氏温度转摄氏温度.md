# 华氏温度转摄氏温度

[对应练习代码](<1.华氏温度转摄氏温度.py>)

### 思路与知识点

读取华氏温度，用公式 `c = (f - 32) / 1.8` 转换，再按一位小数输出。

### 运行说明与易错点

`input` 返回字符串，要先用 `float` 转换。`%.1f` 控制的是显示精度，不是变量保存的精度。

### 练习代码

```python
f=float(input('please enter a float number: '))
c=(f-32)/1.8
print("%.1f华氏度=%.1f摄氏度"%(f,c))
```

### 检查结果

输入 `32`，输出 `32.0华氏度=0.0摄氏度`；输入 `212`，摄氏温度为 `100.0`。
