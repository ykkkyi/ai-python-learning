# 计算圆的周长和面积

[对应练习代码](<2.计算圆的周长和面积.py>)

### 思路与知识点

根据半径计算周长 `2πr` 与面积 `πr²`。

### 运行说明与易错点

原练习把 π 写为 `3.1416923`；下面的整理示例改用标准库 `math.pi`。输入半径应为非负数。

### 整理后的参考代码

下面修正了上述问题；链接中的 `.py` 保留原练习记录，复习时可以对照修改。

```python
radius=float(input("请输入圆的半径:"))
from math import pi
perimeter=pi*2*radius
area=pi*radius*radius
print("周长%.3f"%perimeter)
print("面积%.3f"%area)
```

### 检查结果

输入 `1`，周长输出 `6.283`，面积输出 `3.142`。
