# 判断闰年

[对应练习代码](<3.判断闰年.py>)

### 思路与知识点

能被 4 整除但不能被 100 整除，或者能被 400 整除的年份满足示例中的闰年判断条件。

### 运行说明与易错点

`%` 求余数，`and` 和 `or` 组合条件。括号明确每组条件的含义。

### 练习代码

```python
year = int(input('请输入年份: '))
is_leap = (year % 4 == 0 and year % 100 != 0) or year % 400 == 0
print(f'{is_leap = }')
```

### 检查结果

分别输入 `2000`、`1900`、`2024`、`2023`，布尔结果应为 `True`、`False`、`True`、`False`。
