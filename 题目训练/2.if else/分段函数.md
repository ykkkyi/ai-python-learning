### 思路与知识点

按 `x > 1`、`-1 <= x <= 1`、`x < -1` 三个区间，分别使用 `3*x - 5`、`x + 2`、`5*x + 3`。

### 运行说明与易错点

原提示写“整数”，实际使用 `float` 接收实数，整理示例已修改提示。`elif x >= -1` 的上限由前面的条件保证。

### 整理后的参考代码

下面修正了上述问题；链接中的 `.py` 保留原练习记录，复习时可以对照修改。

```python
x=float(input('请输入一个实数:'))
if x>1:
    y=3*x-5
elif x>=-1:
    y=x+2;
else:
    y=5*x+3
print(f'{y=}')
```

### 检查结果

输入 `2` 得到 `y=1.0`；输入 `1` 得到 `y=3.0`；输入 `-1` 得到 `y=1.0`；输入 `-2` 得到 `y=-7.0`。
