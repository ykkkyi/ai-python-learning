# 三角形的周长和面积

[对应练习代码](<三角形的周长和面积.py>)

### 思路与知识点

先验证任意两边之和大于第三边，再用海伦公式计算面积：半周长为 `p`，面积为 `(p*(p-a)*(p-b)*(p-c))**0.5`。

### 运行说明与易错点

三个输入分别占一行。边长按正实数输入；退化三角形不满足严格大于条件。

### 练习代码

```python
a=float(input())
b=float(input())
c=float(input())
if a+b>c and a+c>b and b+c>a:
    p=(a+b+c)/2
    perimeter=a+b+c
    area=(p*(p-a)*(p-b)*(p-c))**0.5
    print(f'周长={perimeter}')
    print(f'面积={area}')
else:
    print("不能构成三角形")
```

### 检查结果

依次输入 `3`、`4`、`5`，周长为 `12.0`，面积为 `6.0`；输入 `1`、`2`、`3`，输出不能构成三角形。
