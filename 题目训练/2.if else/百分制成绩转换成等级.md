# 百分制成绩转换成等级

[对应练习代码](<百分制成绩转换成等级.py>)

### 思路与知识点

按分数从高到低检查条件，依次映射为 A、B、C、D、E 五档。

### 运行说明与易错点

原练习假定输入在 0～100 之间，尚未验证范围。复习时重点检查 60、70、80、90 这些分界点。

### 练习代码

```python
score=float(input())
if score>=90:
    grade='A'
elif score>=80:
    grade='B'
elif score>=70:
    grade ='C'
elif score>=60:
    grade='D' 
else:
    grade='E'
print(f'{grade=}')
```

### 检查结果

输入 `90` 得到 `grade='A'`，输入 `60` 得到 `grade='D'`，输入 `59` 得到 `grade='E'`。
