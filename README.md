# AI Python Learning

这是我的 8 周 Python 与 AI 入门学习仓库。

当前目标：

- 学会 Python 基础语法、函数、文件操作和异常处理
- 熟悉 Git / GitHub 的基本工作流
- 掌握 NumPy、Pandas、Matplotlib 的数据分析基础
- 完成一个可展示的数据分析小项目

## 8 周路线

| 周次 | 主题 | 主要产出 |
| --- | --- | --- |
| Week 01 | Python 基础语法 | 基础练习、词频统计、成绩统计 |
| Week 02 | Python 进阶与代码组织 | 类、日志、测试、小程序 |
| Week 03 | Git / GitHub / Shell | Git 笔记、Shell 笔记 |
| Week 04 | NumPy | 数组与矩阵计算练习 |
| Week 05 | Pandas | 数据读取、清洗、分组统计 |
| Week 06 | Matplotlib | 数据可视化图表 |
| Week 07 | 数据分析项目 | Titanic 或其他真实数据分析 |
| Week 08 | 总结与机器学习预习 | 作品集整理、sklearn 初步 |
