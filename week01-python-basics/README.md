# Week 01: Python 基础语法

本周目标：从 C++ 思维切换到 Python 思维，能写简单脚本，能读写文件，能把练习代码提交到 GitHub。

## 学习资料

- 廖雪峰 Python 教程：Python 基础、函数、模块、错误调试、IO 编程
- 莫烦 Python：Python 基础部分

## 每天任务

### Day 1: 仓库初始化与 Python 基础

任务：

- 检查 Python / Conda / Git 是否安装成功
- 学习变量、数字、字符串、输入输出
- 运行 `basic_syntax.py`
- 在 `notes.md` 写下今天的 5 条笔记

命令示例：

```bash
python --version
conda --version
git --version
python week01-python-basics/basic_syntax.py
```

### Day 2: list / tuple / 字符串

任务：

- 练习列表增删改查
- 练习切片
- 写一个简单的成绩列表统计

### Day 3: dict / set / 条件 / 循环

任务：

- 用字典统计词频
- 用集合去重
- 练习 `for` 和 `while`

### Day 4: 函数

任务：

- 写 5 个函数：求和、平均数、最大值、阶乘、判断素数
- 理解默认参数、关键字参数

### Day 5: 文件读写与异常处理

任务：

- 读取文本文件
- 写入统计结果
- 使用 `try...except` 处理错误

### Day 6: 综合练习

任务：

- 完成词频统计脚本
- 完成学生成绩统计脚本

### Day 7: 总结

任务：

- 整理 `notes.md`
- 更新根目录 `README.md` 的进度
- 提交本周代码
