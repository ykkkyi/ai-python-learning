# Week 01 Notes

## Day 1: print / input / 变量

### 今天学了什么

- `print()` 用来输出内容。
- `input()` 用来接收用户输入，得到的结果默认是字符串。
- Python 变量不需要提前声明类型。
- `int()`、`float()`、`str()` 可以做基础类型转换。
- `type()` 可以查看变量当前类型。

### 遇到的问题

- 把 `input()` 得到的字符串直接和数字相加会报错。

### 解决方法

```python
age = int(input("请输入年龄："))
print(age + 1)
```
